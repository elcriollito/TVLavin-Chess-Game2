About CAISSA Chess

AI-powered chess analysis for everyone

Our Mission

CAISSA Chess exists to democratize chess analysis. We believe every chess player, from beginner to master, deserves access to powerful, intuitive tools for improving their game.

Traditional chess analysis tools are either too expensive, too complex, or too limited. We're building a free, open platform that combines the power of Stockfish with modern AI to make chess analysis accessible, educational, and enjoyable.

What Makes CAISSA Different

Engine-Powered Analysis

Stockfish 17 running in your browser with full multi-variant analysis and opening book integration.

AI Mentor

LLM-powered explanations that translate engine evaluations into human-readable strategic insights.

Smart Library

Save positions, games, and analysis with cloud sync. Query your library with natural language.

CAISSA Insight

Analyze your entire Chess.com game history to identify patterns, mistakes, and improvement areas.

Engine vs Engine

Watch AI battle AI. Test openings, explore positions, and learn from computer play.

Position Forge

Build custom positions with drag-and-drop editing and instant FEN generation.

Technology Stack

CAISSA Chess is built with modern web technologies to run entirely in your browser with no server-side game processing:

  • Stockfish 17 WebAssembly – World's strongest chess engine, compiled to run natively in browsers
  • Chess.js – Move validation and game logic
  • Chessboard.js – Interactive board UI with drag-and-drop
  • LLM Integration – Together.ai, OpenAI, Anthropic, and Llama API support for chess explanations
  • IndexedDB – Client-side storage for your library and analysis
  • Supabase – Cloud sync and user authentication
  • Vercel – Serverless API endpoints and edge deployment

Privacy & Data

Your privacy matters. Here's how we handle your data:

  • Local-First – All game analysis runs in your browser. We never see your positions or games.
  • Optional Cloud Sync – You choose whether to sync your library to the cloud. Sync is off by default.
  • No Tracking – We don't use Google Analytics or third-party trackers.
  • Open Source – Our code is transparent and auditable on GitHub.
  • Your API Keys – AI Mentor uses your own API keys. We never store them permanently.
