# Client Requirements

## Packages

**chess.js** | Chess game logic and validation

**react-chessboard** | React component for the chess board with built-in piece SVGs

**framer-motion** | Smooth animations for UI elements

**date-fns** | Formatting dates for game history

## Notes

Stockfish worker is expected at `/stockfish-worker.js`

Backend provides `/api/games` endpoints for saving game history
