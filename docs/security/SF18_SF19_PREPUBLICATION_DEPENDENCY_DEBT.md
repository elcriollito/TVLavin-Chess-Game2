Recorded 2026-09-22 against certified runtime `49dff5a684be32e9e40848fc0a52afa37aaf6898`. Owner: CAISSA Release Engineering. Review/expiry: 2026-09-24. This is a separate dependency-maintenance item, not an engine-release dependency change or a claim that `npm audit` passes.

`package.json` and `package-lock.json` are byte-identical to `origin/main` (`a6473ce0269dc78628de86b010f15a2667db8fcf`); lockfile blob `13b98b4f6b57cbb7bb74641a6405ab488878463c`. The release introduced none of these versions. `npm audit --json --package-lock-only` reports four vulnerable package nodes (two high, two moderate; zero critical), representing five underlying advisories. The `stripe` node is a derived `qs` warning, not a sixth advisory. This assessment is static; it does not assert that a hypothetical upstream compromise or future route cannot make a path reachable.

Priority within this debt: `adm-zip` upstream/archive review first, `sharp` acceptance expiry second, `qs` override third, local symlink extraction fourth. This does not waive future advisories. The supply-chain script pins the existing versions, so dependency remediation will require its policy update and a fresh regression gate; no package version or lockfile is changed here.
