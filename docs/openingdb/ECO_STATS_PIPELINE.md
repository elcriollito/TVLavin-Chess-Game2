# ECO Stats Pipeline

This pipeline builds lightweight ECO stats JSON files from a large local PGN database.

## Why

- Large PGNs (GBs) are processed offline only.
- `/eco` page reads small JSON files from `public/data/eco/`.
- Browser never parses the large PGN.

## Run

```bash
node experimental/openingdb-research/build-eco-stats.mjs "D:\Chess\DB\mydb.pgn"
```

Options:

```bash
node experimental/openingdb-research/build-eco-stats.mjs <pgn-path> --max-ply 60 --top 20 --out-dir public/data/eco
```

## Outputs

Written to `public/data/eco/`:

- `eco_stats.json`
- `eco_popular_continuations.json`
- `eco_fen.json` (optional helper map, generated by default)

## Runtime Notes

- Script streams the PGN line-by-line.
- Broken/invalid games are skipped safely.
- ECO classification uses PGN `[ECO "..."]` first, but an ECO header is not proof that the recorded moves belong to that code.
- If ECO tag is missing, a best-effort prefix match is used from local ECO definitions.

## Audit requirements

Generated aggregates are **unverified** until all of the following are retained and checked:

- source PGN identity, digest, acquisition date, and usage rights;
- generator version and complete build parameters;
- game counts that exactly equal White wins + draws + Black wins;
- legal replay of every published continuation;
- position-level ECO classification against the pinned opening source, including transpositions;
- a reviewable trace from each published aggregate back to its contributing games.

If those artifacts are missing or a code contains unrelated lines, remove that code from served JSON, retain the old row in a source-only audit file, and render statistics as unavailable. Do not infer values from adjacent ECO codes.

The runtime derives selected boards from legal move replay. `eco_fen.json` is not a trusted fallback and is not loaded by the canonical `/eco` page.

## Safety

- Do not commit the source PGN file.
- Commit a provenance/build manifest and audit evidence alongside any generated JSON selected for serving.
