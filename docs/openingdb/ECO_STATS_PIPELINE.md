# ECO Stats Pipeline

This pipeline builds lightweight ECO stats JSON files from a large local PGN database.

## Why

- Large PGNs (GBs) are processed offline only.
- `/eco` page reads small JSON files from `public/data/eco/`.
- Browser never parses the large PGN.

## Run

```bash
node experimental/openingdb-research/build-eco-stats.mjs "D:\Chess\DB\mydb.pgn"
```

Options:

```bash
node experimental/openingdb-research/build-eco-stats.mjs <pgn-path> --max-ply 60 --top 20 --out-dir public/data/eco
```

## Outputs

Written to `public/data/eco/`:

- `eco_stats.json`
- `eco_continuations.json`
- `eco_fen.json` (optional helper map, generated by default)

## Runtime Notes

- Script streams the PGN line-by-line.
- Broken/invalid games are skipped safely.
- ECO classification uses PGN `[ECO "..."]` first.
- If ECO tag is missing, a best-effort prefix match is used from local ECO definitions.

## Safety

- Do not commit the source PGN file.
- Commit only generated JSON files if desired.
