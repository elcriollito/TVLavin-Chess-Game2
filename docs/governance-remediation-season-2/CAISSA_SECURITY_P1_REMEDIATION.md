## Discovered parse repair

`cloudflare-worker/worker.js` contained five malformed BigInt literals that prevented module import. They were repaired only to restore valid JavaScript and allow the numeric-limit tests. This was a pre-existing correctness defect, not proof that every Polyglot random constant is correct. Exact opening-book hash validation remains a separate release check.
