# CAISSA Classic Style Guide

Status: Season 4.3F foundation

## Purpose

CAISSA Classic is a nostalgic chess-room experience inspired by classic desktop internet clients while using original CAISSA identity, language, and interaction design.

It should feel like a living chess client, not a replica of another brand.

## Design Philosophy

- Preserve nostalgia without copying protected assets.
- Prefer compact information density.
- Keep interactions calm, direct, and desktop-like.
- Use visible states instead of modern animation.
- Treat CAISSA Lobby as the center of the classic experience.

## Typography

Use classic system fonts:

- Tahoma
- Arial
- MS Sans Serif
- Verdana
- Courier New for console, chat, and activity feed details

Avoid modern display fonts inside CAISSA Classic.

## Buttons

Buttons should use Windows 98 style interaction:

- Raised bevel by default.
- Pressed bevel on active state.
- Dotted focus rectangle.
- Compact padding.
- No modern shadows.
- Cursor remains classic/default unless accessibility requires otherwise.

## Panels

Panels should use:

- Raised or sunken borders.
- Compact headers.
- Dense rows.
- Small separators.
- Internal scroll areas where content grows.

## Iconography

Use simple text or chess-symbol icons:

- Pawn for lobby.
- White pawn for beginner areas.
- Knight for casual play.
- Bishop for blitz.
- Rook for rapid.
- King for classical play.
- Queen for masters.
- Trophy-like or crossed-sword symbol for tournaments.
- Eye-style symbol for spectator areas.
- Gear for computer lounge.

Do not use protected third-party imagery.

## Official Rooms

- CAISSA Lobby
- Beginner Hall
- Casual Room
- Blitz Room
- Rapid Room
- Classical Room
- Masters Lounge
- Tournament Hall
- Spectator Gallery
- Computer Lounge

## Terminology

Preferred terms:

- CAISSA Classic
- CAISSA Lobby
- Room Tables
- Classic Activity Feed
- Player List
- Table
- Watch
- Join
- Stand

Avoid brand references to external legacy services in user-facing UI.

## Tone

Copy should be:

- Short.
- Friendly.
- Practical.
- Period-appropriate.
- Not overly playful.

Examples:

- Connected to FICS.
- Inside CAISSA Lobby.
- Watching Table 18.
- Player joined.
- Table opened.

## Sound Hooks

Season 4.3F defines future sound cue names only:

- connect
- disconnect
- move
- join
- notify
- error

No audio playback is implemented in this phase. Future work should route these cues through the existing user-controlled sound preference system.
