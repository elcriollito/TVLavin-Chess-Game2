🎮 WHAT IS THIS?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  A modern chess web app with TWO AI engines:

  🐟 Stockfish - Classic chess engine (fast, strong)
  🤖 LLM - AI that explains its thinking (Claude/GPT)

  Play against AI, watch AI vs AI, and learn from
  the LLM's reasoning!


🎯 QUICK TOUR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Once the app opens at http://localhost:3000:

  ✅ Board appears with pieces
  ✅ Left panel = Stockfish analysis
  ✅ Right panel = LLM controls
  ✅ Bottom = Game mode selector

  Click "Human vs LLM" and start playing!

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ❌ Node.js not found?
     → Install from https://nodejs.org/

  ❌ npm install fails?
     → Check internet connection
     → Run as administrator

  ❌ Port 3000 in use?
     → Edit vite.config.ts, change port

  ❌ Board doesn't load?
     → Clear browser cache (Ctrl+Shift+R)

  📖 See KNOWN_ISSUES.md for more fixes
