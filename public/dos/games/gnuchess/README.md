# GNU Chess (DOS Version)

**Phase 2 Self-Hosted Bundle**

## About

GNU Chess is a free software chess engine developed by the Free Software Foundation. This DOS version represents an early implementation of the GNU Chess engine, designed to run on MS-DOS systems.

## Bundle Contents

This bundle contains:
- `GNUCHESS.EXE` - DOS executable
- `GNUCHESS.DAT` - Opening book data (if applicable)
- Supporting files for DOS execution

## Running in Browser (via DOSBox)

When DOSBox integration is enabled in CAISSA:

1. Click "Play (Hosted)" button on the GNU Chess card
2. CAISSA loads the bundle via js-dos (DOSBox WebAssembly)
3. Game runs in browser sandbox
4. No installation required

## Running Locally (Manual)

If you download this bundle:

1. Extract `gnuchess.zip`
2. Use DOSBox or similar DOS emulator
3. Mount the directory and run `GNUCHESS.EXE`
