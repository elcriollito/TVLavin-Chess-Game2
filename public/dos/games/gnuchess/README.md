# GNU Chess DOS placeholder

This directory does **not** currently distribute a GNU Chess executable or
opening-book data. `gnuchess.zip` contains only `PLACEHOLDER.txt` and
`README.txt`; it must not be described as a playable or complete GPL binary
bundle.

The adjacent `LICENSE.txt` is retained as historical/reference material. It
does not prove the provenance of a future executable.

Before a real GNU Chess DOS build is added, record and verify:

- the exact upstream version and source URL;
- the archive and executable SHA-256 digests;
- the applicable GPL license and copyright notices;
- the version-matched corresponding source and build instructions;
- the js-dos runtime version actually delivered to users; and
- a browser smoke test of the immutable, checksummed bundle.

Official project information: https://www.gnu.org/software/chess/
